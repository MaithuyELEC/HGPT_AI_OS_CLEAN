# Lucid AI Studio v1.0.0 Release Notes

## Version

1.0.0

## Release Date

July 18, 2026

## Highlights

- Initial public release of Lucid AI Studio.
- Production-ready macOS application bundle included.
- macOS DMG installer included.
- Final release artifacts staged under `release/Final/`.

## Brand Identity

- Final Lucid AI Studio brand assets included in SVG, AI, EPS, PDF, PNG, ICO, and ICNS formats.
- Release packaging preserves the approved Lucid AI Studio product name and visual identity.

## Known Limitations

- Windows installer is included only when the final Windows setup executable is available in the build outputs.
- macOS distribution may require user approval depending on local Gatekeeper and code-signing policy.
- External AI provider behavior depends on configured provider credentials and availability.

## System Requirements

- macOS: macOS 12 Monterey or later recommended.
- Windows: Windows 10 or later when Windows installer is available.
- Disk Space: 2 GB available space recommended.
- Network: Required for cloud AI provider access.
